# Excalet Global Ventures Ltd.

Software Engineering Internship Project

## Overview

This repository contains a website developed as part of my Afriment Internship Program.

During the internship, I was assigned to work with the Excalet Integrated Services group, now operating as Excalet Global Ventures Ltd., in the role of Software Engineer.

The project focuses on designing and developing a professional digital presence for the organization through a modern, responsive and user-friendly website.

## About Excalet

Excalet Global Ventures Ltd., formerly Excalet Integrated Services, is a Nigerian diversified services company headquartered in Owerri, Imo State, Nigeria.

The company provides services across:

* Facility Management
* Industrial and Commercial Cleaning
* Fumigation and Pest Control
* Environmental and Sanitation Services
* Agriculture and Agro-allied Activities
* Equipment Services
* Other Business Ventures

## My Role

Software Engineer — Internship

## Project

The website serves as a digital representation of Excalet Global Ventures Ltd., presenting information about the company, its services, business areas and corporate identity.

The project was developed as a static client-side website, with no requirement for a dedicated backend or database.
